Motion

Two speeds. UI responds immediately and briefly; isometric objects turn slowly and come to rest. There is nothing in between.

Durations

Hover the tiles — each object tips into the isometry, at a different duration.

Principles

Do

  • Move along the brand angles — isometric objects travel on 26.57°, not straight down.
  • Let lime appear through movement: an edge lights up as it is reached.
  • Shift the arrow 4 px right on hover. That is the standard feedback.
  • On scroll, animate position and opacity only — never scale.

Don't

  • No parallax on text.
  • No bounce or elastic curves — the brand does not spring.
  • No infinite loops other than the hero artwork.
  • No animation that shifts content while the page loads.

Reduced motion

prefers-reduced-motion: reduce sets all four durations to 1 ms — states then switch instantly instead of animating. That is already in tokens.css and applies automatically to any component built on the tokens. Hero video and infinite loops need to be stopped separately: 

@media (prefers-reduced-motion: reduce) {
  .cf-hero__media video { display: none; }
  .cf-hero__media img   { display: block; } /* still frame instead */
}

Hero artwork

The landing page hero runs an isometric loop (05-motion/hero-abstract-art.mp4): slowly shifting planes in CF-Grau with lime edges. Rules for embedding it:

  • muted, loop, playsinline, autoplay — never with sound.
  • A poster with the first frame, so the hero is there immediately.
  • Under reduced motion, only the poster is shown.
  • The headline sits on top of the video and needs at least 4.5:1 there — if in doubt, darken the lower half.
