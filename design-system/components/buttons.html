Components

Buttons

Rectangular, mono uppercase, arrow on the right. The arrow is not decoration — it says the action leads somewhere, and it moves 4 px in that direction on hover.

Variants

Primary

The lime gradient — the light layer. Exactly one primary button per screen.

<button class="cf-btn cf-btn--primary">
  Kontakt aufnehmen
  <svg class="cf-arrow" aria-hidden="true"><use href="#cf-arrow"></use></svg>
</button>

Glass

For the hero: the same gradient, but with a frosted edge so it holds on moving artwork.

Outline

Secondary actions. The 1 px contour is the brand's default frame.

Solid

On light, busy surfaces where a contour would disappear.

Ghost

An underlined inline link. For tertiary actions close to body copy.

Buttons are set wide rather than shrunk to their content: label left, arrow at the right edge. That is the shape from the design. In narrow contexts use .cf-btn--block for full width.

The arrow sprite

In this documentation the sprite is injected by JavaScript. On the website it belongs directly after <body> in the page template — once per page:

Rules

Do

  • One primary per screen; everything else outline or ghost.
  • Use verbs in the label: “Kontakt aufnehmen”, not “Kontakt”.
  • <a> for navigation, <button> for actions.
  • Disabled states via the disabled attribute plus a --grey-200 surface.

Don't

  • No icons other than the CF arrow.
  • No rounded corners, no shadows.
  • No primary button on a lime surface.
  • No lowercase labels — the mono uppercase is part of the brand.
