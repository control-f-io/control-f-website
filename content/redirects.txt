# The old site's addresses, and where each one now lives.
#
# www.control-f.io was a Wix site until the domain moved to this one, and every
# address it published — its sitemap listed twelve pages, fifteen posts and two
# blog categories — is a link somebody may still hold: a search result, a
# LinkedIn post, a bookmark, a printed footer. A link that lands on the 404
# page is a reader lost and a ranking dropped, so each one is answered here.
#
# ONE LINE PER OLD ADDRESS: the path as Wix served it, then the shipped page it
# now means. scripts/stage-site.py turns this table into what each host can do:
#
#   GitHub Pages   cannot answer with a 301, so every line becomes a stub page
#                  under the old path (Pages serves post/x.html at /post/x)
#                  that meta-refreshes to the new address and names it as its
#                  canonical — the shape Google reads as a permanent redirect.
#   the Worker     gets the same table as Cloudflare's _redirects file, so the
#                  same links answer 301 if that host ever serves the site.
#
# The target is written as build-site.py ships it — blog/<slug>.html, not
# beitrag-<slug>.html — and "/" for the landing page. --check refuses a target
# that is not a shipped page and a source that would shadow one, so a post
# that is renamed or withdrawn fails the deploy here rather than sending
# readers to a page that is gone.
#
# WHY THESE TARGETS. Every page and post was matched by title against the
# archive. Four had no counterpart and go to the nearest page that does:
#
#   /predictivemaintenance        a service page; expertise.html is the offering
#   /project-manager, and its    the opening is closed; karriere.html lists
#     /post/ twin                  the ones that are open
#   /post/datenplattform-fuer-…   two posts that were not carried over; the
#   /post/ki-token-kosten-…       archive is where their readers find the rest
#
# Non-ASCII paths are written exactly as Wix's sitemap listed them. The stub
# for GitHub Pages carries that name; the Worker's line matches on the ASCII
# prefix and a splat, because that is the one form that matches whatever
# encoding a browser or a crawler sends.
