## Your role

As a DevOps Engineer, you will take the lead in building, automating, and securely operating our Azure-based data platform. You will develop robust CI/CD processes in Azure DevOps, implement Infrastructure as Code with Terraform, and ensure the reliable operation of Azure Databricks. You will put your own concepts and ideas into practice and actively shape the platform.

Type of position: Full-time, permanent employment

Salary: Depending on experience level, we offer €65,000.00 to €85,000.00 per year.

## Your responsibilities

- Designing, building, and operating CI/CD pipelines with Azure DevOps (Repos, Pipelines, Artifacts, Environments)

- Implementing Infrastructure as Code with Terraform: modular structures, state management, and lifecycle management of Azure resources

- Provisioning and operating Azure Databricks (workspaces, cluster policies, jobs/workflows, libraries, secrets), including automation via Terraform and CLI

- Standardizing deployments across development, test, and production environments, including approval processes and controlled rollouts

- Building and continuously improving monitoring and alerting (Azure Monitor, Log Analytics, optionally New Relic)

- Security by design: Azure AD, RBAC, Key Vault, network and access concepts (VNET, Private Endpoints, NSGs)

- Troubleshooting, incident analysis, and sustainable remediation in complex cloud environments

- Working closely with development and data teams in an agile process (Scrum/Kanban)

## Your profile

### Requirements

- Practical experience with Microsoft Azure (portal, resource model, subscription and resource group concepts)

- Solid knowledge of Azure DevOps (Pipelines, Repos, Service Connections, Variable Groups, Environments)

- Proven experience with Terraform in production environments — structured implementation of IaC (modular approaches, state management, workspaces, versioning) and integration into CI/CD processes

- Scripting and automation with PowerShell and/or Bash, ideally also Python

- Understanding of security and networking fundamentals (IAM/RBAC, TCP/IP, least privilege)

- A structured way of working, analytical thinking, and the ambition to continuously improve complex systems

### Nice to have

- Experience with Azure Databricks (jobs/workflows, cluster policies, permissions, secrets)

- Container know-how (Docker, Kubernetes/AKS)

- Azure Landing Zones, Policy as Code, GitOps approaches

- Observability and tracing (Azure Monitor, App Insights, Log Analytics, New Relic)

- Experience with data platform components, such as storage and network setups for data workloads
